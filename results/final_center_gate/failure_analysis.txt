ROOT CAUSE ANALYSIS
----------------------------------------
This failure occurred in a DRAM array region where the
pattern is highly periodic (word-line/bit-line grid repeats
every 3-10 pixels at search resolution). The ZNCC matcher
produced multiple peaks of nearly equal height at adjacent
grid cells. The deterministic disambiguator could not resolve the
ambiguity because the local 100x100 patch lacked distinctive
features (no mat boundary, no missing/shifted contact via).

The algorithm selected the peak closest to the search image
center, but the true location was at a different grid repeat.

PROPOSED FIX
----------------------------------------
1. Increase macro-context and evaluate candidate locations across
   multiple acquisition transforms rather than one local repeat.
2. Calibrate the disambiguation weights on a held-out validation
   set and report confidence alongside the predicted location.
3. If the reference crop is known to contain a mat/strip boundary,
   weight boundary-containing candidates higher.
